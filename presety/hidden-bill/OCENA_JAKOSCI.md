# Kryteria jakości The Hidden Bill

To arkusz oceny redakcyjnej, nie nowa funkcja bota. Istniejący silnik nie
ładuje automatycznie tego pliku. Najważniejsze reguły są również w
`prompty/linia_redakcyjna.md` i blokach głosu, które rzeczywiście czyta.

**Warunki konieczne, niezależne od stylu:**

- Każdy sprawdzalny fakt ma podstawę w dostępnej karcie dowodowej.
- Liczby zachowują warunki porównania, jednostki, okres i zakres.
- Zarzut, ustalenie, ugoda i obecna polityka nie są mieszane.
- Język, konto, temat i źródła należą do tej redakcji.
- Tekst nie zawiera fikcyjnego doświadczenia ani faktów z korpusu stylu.
- Tytuł obiecuje dokładnie to, co tekst wyjaśnia.

Naruszenie któregokolwiek warunku oznacza odrzucenie lub poprawę, nawet
jeśli materiał jest atrakcyjnie napisany.

**Ocena 0–2 w pięciu wymiarach:** 0 = brak, 1 = częściowo, 2 = wyraźnie.

| Wymiar | Pytanie oceniającego |
|---|---|
| Rozpoznanie | Czy czytelnik od razu rozumie, jakiego zakupu dotyczy tekst? |
| Odkrycie | Czy dowiedział się konkretnej rzeczy ponad „firmy chcą zarabiać”? |
| Wyjaśnienie | Czy rozumie mechanizm, a nie tylko zna niekorzystny przypadek? |
| Użyteczność | Czy umie lepiej porównać ofertę lub wskazać ważny warunek? |
| Głos | Czy tekst jest naturalny, uważny i samodzielny, bez sloganu i nadęcia? |

Proponowany próg redakcyjny: 8/10 oraz wszystkie warunki konieczne.
To początkowa polityka oceny, nie zweryfikowany statystycznie predyktor
zasięgów i nie nowa, zaimplementowana bramka silnika.

**Próby odporności przed uruchomieniem nowego tematu:**

| Materiał wejściowy | Oczekiwane zachowanie |
|---|---|
| Ktoś pokazuje droższą cenę po ponownym wejściu na stronę | Nie ogłaszać personalizacji bez dowodu jej przyczyny |
| Komunikat o pozwie wobec firmy | Zachować język zarzutów, sprawdzić aktualny stan sprawy |
| Cena w promocji bez warunków odnowienia | Nie wyliczać pozornego rocznego kosztu; znaleźć warunki lub zawęzić tekst |
| Dokument z UK i odbiorca z USA | Nazwać jurysdykcję, nie obiecywać amerykańskiemu czytelnikowi tego samego prawa |
| Prawdziwie korzystna oferta z przejrzystymi zasadami | Dopuścić pozytywny wniosek, nie wymyślać pułapki |
| MYSL bez karty dowodowej | Ocena lub pytanie; bez firm, statystyk i zmyślonych doświadczeń |
| Wpis o cenie akcji lub nowym modelu AI | Odrzucić, jeśli nie dotyczy realnego zakupu konsumenckiego |
| Materiał tylko powtarza tezę znanej publikacji | Szukać odrębnego dokumentu i pytania albo odrzucić |

**Pomiar pierwszych czterech tygodni:** porównywać zaakceptowane
materiały, czas i koszt wszystkich prób, udział poprawek, reakcje na
1000 wyświetleń, restacki na 1000 wyświetleń oraz nowych subskrybentów,
jeśli platforma pozwala przypisać ich do publikacji. Nie mieszać
wskaźników z różnych definicji ani traktować braku danych jako zera.

Nie optymalizować wyłącznie polubień. Ważniejszy jest tekst, który
czytelnik potrafi komuś przekazać i uzna za powód do kolejnej lektury.
Nie zmieniać naraz stylu, tematu, modelu i godzin po jednym słabszym wpisie.
Przy tak małej próbie wyniki służą do kierowania dalszym sprawdzaniem,
nie do ogłaszania pewnej przewagi strategii.
