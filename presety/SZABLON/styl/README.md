# styl/ — glos tego kartridza

- `profil_pozytywny.md` — do czego dazy pisarz artykulu.
- `profil_negatywny.md` — czego nie wolno w artykulach i notkach.
- `korpus.txt` (opcjonalnie) — TWOJE wlasne teksty, akapity oddzielone
  pusta linia; nigdy cudza opublikowana publicystyka. Po dodaniu wskaz plik
  w `preset.toml` (`styl.korpus = "styl/korpus.txt"`) i przypnij:
  `python narzedzia/przypnij_styl.py --pokaz`.

Obie sciezki profili w `preset.toml` sa wzgledem katalogu presetu.
