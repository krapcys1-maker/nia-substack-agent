# NIA media

`nia-demo.mp4` is the reviewed 92-second, 1920 × 1080 product film, with English
AI narration and an original synthesized soundtrack. `nia-demo-poster.jpg`
is its cover; `nia-demo-chapters.json` contains chapter timing and the narration
transcript. The `.srt` files provide English and Polish subtitles.

`nia-article.png`, `nia-note.png`, `nia-comment.png`, `nia-restack.png` and
`nia-subscription.png` are cropped views of the verified Substack results.
See [the demo page](../DEMO.md) for live links and recording context.

`overview.svg` is an original, editable vector diagram of the product:
engine → editorial preset → private instance. It is an explanatory graphic,
not a screenshot of a graphical bot dashboard.

The browser recording workflow is documented in [RECORDING.md](../RECORDING.md).
Public demo exports belong here only after visual and privacy review. Raw
recordings remain in the private instance, outside Git.
