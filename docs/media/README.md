# NIA media

`nia-demo.mp4` is the reviewed 92-second, 1920 × 1080 product film, with English
AI narration and an original synthesized soundtrack. `nia-demo-poster.jpg`
is its cover; `nia-demo-chapters.json` contains chapter timing and the narration
transcript. The `.srt` files provide English and Polish subtitles.

`nia-article.png`, `nia-note.png`, `nia-comment.png`, `nia-restack.png` and
`nia-subscription.png` are cropped views of the verified Substack results.
See [the demo page](../DEMO.md) for live links and recording context.

README and the demo page embed the GitHub-hosted video attachment as a bare URL
on its own paragraph. This produces GitHub's inline player. A link to the MP4
in the repository or a release is only a file/download link, not an embed.

`overview.svg` is an original, editable vector diagram of the product:
engine → editorial preset → private instance. It is an explanatory graphic,
not a screenshot of a graphical bot dashboard.

The browser recording workflow is documented in [RECORDING.md](../RECORDING.md).
Public demo exports belong here only after visual and privacy review. Raw
recordings remain in the private instance, outside Git.

## Repository identity

`nia-workflow.svg` is the compact README workflow graphic. Its text is also
described in the README, so the graphic is not required to understand the product.

`nia-social-preview.svg` is the editable source for `nia-social-preview.png`
(1280 × 640). The PNG is intended for GitHub's repository social preview and
sharing the project. It is a product illustration, not a dashboard screenshot.
To set it on GitHub, use **Settings → General → Social preview → Edit → Upload an image**.
See [GitHub's social preview guide](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
Committing the image alone does not change GitHub's social preview setting.

The palette follows the product film: cream `#f3f1e8`, forest `#182e26`, orange
`#ee5b32`, muted text `#59645b`, and warm white `#fffefa`. Typography uses Segoe UI
with Arial and sans-serif fallbacks. Keep the inline video near the top of the
README; use the larger social card for sharing rather than above the player.
